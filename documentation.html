Documentation

Connect your application to Modem using the API.

1. Create an application

Add StudentX, iChat or another app and set its sender name.

2. Send OTP

POST /v1/otp/send
{
  "application": "StudentX",
  "phone": user.phone
}

3. Verify

The application sends the OTP entered by the user to the verification endpoint. The actual API should run server-side.
